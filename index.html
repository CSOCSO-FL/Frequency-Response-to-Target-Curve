Frequency Response to Target Curve

Frequency Response to Target CurveTarget Curve to Biquads →

Convert a REW frequency response into a Dirac target curve. The tool measures the average SPL between 500 and 2,000 Hz, subtracts it from the entire response so that band's average is 0 dB, and creates evenly spaced breakpoints on a logarithmic frequency axis.

REW export settings: Select Use custom smoothing → 1/6 smoothing, check Do not include any comments or headers in the export, and check Do not include phase in the export. Export units: SPL; delimiter: Space; number format: REW export format.

1. Frequency response

Reads the first two numeric columns as frequency (Hz) and SPL (dB). Additional columns, such as phase, are ignored. REW export comments and target-curve headers are skipped.

2. Conversion settings

The 500–2,000 Hz reference average is calculated across logarithmic frequency, not by simply averaging unequally spaced rows. Output frequencies use 2 decimal places. The tool does not apply additional smoothing or EQ; export from REW with 1/6-octave smoothing. Fewer breakpoints may miss narrow peaks and dips.

4. Dirac target curve output

Notes: All processing runs locally in your browser. The reference average must be covered by the input data over the full 500–2,000 Hz range. This is a normalized measurement curve, not an inverse correction curve: peaks remain positive and dips remain negative. To make a corrective target instead, you would need to invert the deviation separately. Sharp room nulls and notches may require denser breakpoints.
